# 柚导 · Youdao

**把文案、口播和素材变成可执行的画面设计、分镜、关键帧与制作计划，并在工具可用时推进实际交付。**

当前版本：**v1.5 · 2026-10-05**。适用于支持本地 Skill、文件与工具调用的 AI 智能体。技能入口位于 [youdao/SKILL.md](youdao/SKILL.md)。

柚导提供跨类型导演与制片工作流：先判断作品要让观众理解、感受、记住或采取什么行动，再选择画面、声音、表演和制作方式。它支持剧情、知识类口播、真人表达、产品广告、品牌、活动、文旅、建筑与楼盘影像，以及解释性动效；具体项目设定留在项目文件中。

## 能做什么

| 能力 | 柚导如何工作 | 可交付内容 |
|---|---|---|
| **口播与文案配画面** | 理解观点、条件、证据和情绪，判断保留真人、使用资料、图解、情境插镜或视觉比喻 | 口播区间—画面建议—匹配理由—素材依据—制作路径对应表 |
| **分镜与导演设计** | 组织信息推进、人物目标、动作因果、表演、声音及镜头接点 | 分镜、节拍、表演说明、声画安排和镜头任务卡 |
| **关键帧与视觉资产** | 绑定身份、服装、产品和空间参考，设计关键状态；有可用生图工具时实际生成或编辑并查看结果 | 关键帧、角色/产品图、分镜单图、提示词、参考职责及检查状态 |
| **摄影、空间与灯光** | 查看首帧已知和未知区域，检查遮挡、接触和方向，明确摄影机起点、路径、速度、终点及光源 | 镜头与灯光卡、空间风险判断和必要参考缺口 |
| **动作与连续性** | 将触发、轨迹、接触、反馈与新处境连起来，按实际接受的末态接续 | 动作节拍、接续状态及局部修复方案 |
| **多路径制作** | 按镜头选择实拍、素材复用、生成视频、二维/三维程序动效或混合制作 | 对应制作包；工具具备时产出媒体或可编辑工程 |
| **制片与资产统筹** | 管理版本、参考职责、上游依赖、制作顺序、任务状态和交接 | 资产台账、项目记录、排期/预算依据与交付清单 |
| **检查与迭代** | 分开检查文件、技术规格、语义、空间、动作、画面与声音，定位最小修复范围 | 验收记录、可用片段、尚未核验项和修复方案 |

### 对口播视频特别有用

柚导不会仅按文案里的名词机械配图。它会判断画面到底要证明、解释、对比、定位还是建立感受；抽象关系用可追踪的对象和状态变化呈现，事实证据优先使用可核查素材。已录口播保留原声权限与时间映射，字幕、强调文字和插镜服从真实语义与阅读时间。

当任务要求制作关键帧，且参考和工具齐备时，工作继续到实际生图、查看与保存；只要求建议时，交付画面方案。精确图表与文字可以采用可编辑图形，情境与风格化影像可以调用生图工具。

## 如何使用

安装后直接在任务中调用 `$youdao`，并提供文案、原片、参考或现有项目目录。例如：

> 使用 $youdao，为这段口播推荐对应画面，说明每个画面的匹配理由、素材依据和制作方式。先交画面方案。

> 使用 $youdao，按已确认的分镜制作关键帧，沿用人物参考；调用可用生图工具，检查结果并保存实际图片。

> 使用 $youdao，为这支产品短片设计镜头、灯光和声音。产品性能只使用我提供并确认的资料。

> 使用 $youdao，检查现有片段的动作、空间与接续问题，保留合格部分并提出最小修复方案。

输入不必一次齐全。柚导先查现有文件与上下文，完成可独立推进的工作；仅对会改变核心创意、事实或执行条件的缺口提问。任务可以从开发、配画面、出图、局部修改或验收任一阶段开始。

## 安装

本仓库采用 `youdao/` 技能目录结构。将完整的 `youdao` 文件夹复制到当前宿主的技能目录，保留内部 `agents/`、`references/`、`scripts/` 和 `licenses/`。

在 Codex 中，默认位置为 `$CODEX_HOME/skills/youdao`；未设置 CODEX_HOME 时通常为 `~/.codex/skills/youdao`。复制前先备份已有版本，新一轮对话调用 `$youdao`。

## 工具与能力边界

柚导是给智能体使用的规则与资源，执行者是当前智能体。实际生图、视频、音频、剪辑和渲染依赖宿主提供的工具、素材、权限及有效额度。

- 有生图工具时，可以推进实际关键帧；没有对应工具时，明确缺口并交付已完成的设计材料。
- Three.js、Remotion、FFmpeg 等是按任务选择的候选工具，不是本技能的必需依赖，也不随包附带。
- 平台模式、时长、画幅、参考数量和声音能力按当前工具与资料核验，不承诺跨平台通用参数。
- 静图、提示词、已提交、已下载、技术通过和成片接受分别记录。完整运动和听感需实际观看与试听。
- 项目人物、品牌配色、安全区、账号、路径和设备配置保存在项目记录中，不从上一部片自动继承。

## 分镜检查工具

Python 3 标准库即可运行，无需安装额外依赖：

```bash
python youdao/scripts/check_shots.py path/to/shots.json
```

检查空清单、重复镜头编号、无效时长、主时间线的空档/重叠/乱序、总时长、素材路径、非零文件与接受证据。仅检查结构时使用 `--structure-only`。清单格式与退出码见 [分镜清单规范](youdao/references/shot-manifest.md)。

检查器不联网，不修改输入，不解码媒体，也不判断画面真实或审美。文件存在和检查通过不能替代成片验收。
