# 关键帧生图执行

用于生成或编辑关键帧、分镜单图、人物/产品资产图和情境图。技能负责导演规格与执行路由，图片由当前可用生图工具产生，不宣称技能内置模型或额度。

## 用途与参考

区分概念探索、身份母图、视频首尾帧、合成底板、插图和故事板联系表。母图重稳定识别，首帧重下一动作可行性，底板重合成空间，不让一张拼图承担所有用途。只要建议或提示词时不扩大为出图。

先查已确认资产。改图明确只改什么、保持什么；每张参考标明控制身份、服装、结构、空间、构图或风格哪一项。路径不等于工具已经收到图片，调用前核对实际引用。关键参考缺失只阻止依赖它的图，其他工作继续。

## 单张图规格

图生视频的首尾帧、建筑展示或有复杂接触的图，先按 [空间、镜头与灯光](camera-light-space.md) 查看实际参考，检查可见空间与下一动作的可达性；人物背后和场景深处未知的区域标为推演，不靠提示词补成已核实事实。

沿用镜头ID，按需要描述：对应口播/剧本与观看任务；图的用途；此刻主体、动作状态、接触关系与环境；景别、机位、视线、画幅、占比和文字留白；风格、现场光、材质；参考职责；准确文字；必须保留与允许修改项。下一动作单列给视频，不让静图同时表现整段过程。

使用具体可见状态，不用器材名和“电影感”代替设计。精确品牌字、字幕或图表适合后期叠加时分离底图与文字层；用户要求完整图文画面时按要求生成并逐字检查，不能悄悄省略。

## 实际调用

1. 读取当前 imagegen Skill 与工具定义。宿主提供内置 `image_gen` 时，普通生图/改图优先用内置工具，不要求 API Key，不擅自改用另一付费 API 或模型。其他宿主按实际可用能力适配。
2. 用户已要求出图且必需资料齐备时直接调用，不重复问是否开始。只有缺失会改变身份、事实或核心创意的内容时提问，其他工作继续。
3. 本地参考与编辑目标先实际查看，按工具支持的文件引用或会话图片机制传入；不编附件ID、上传状态或参数。透明图请求真实透明背景并检查输出。
4. 多镜头各有对应规格和参考，沿用共享视觉基准。数量服从用户范围与必要状态。已有合格图优先复用或局部编辑，避免反复从零重抽造成漂移。
5. 等待真实结果，检查输出。失败保留规格和已完成图，说明具体缺口；不拿文字框、无关图片或占位图报称完成。

可用模型、尺寸、保存位置和引用方式以当前工具说明为准，不将本模块当版本手册。内置工具不可用时不悄悄改走付费调用。

## 验图与交付

实际查看每张交付图：匹配的含义是否准确；身份与结构；手物接触；构图、文字空间、方向、光线；精确文字；镜头连续性；是否能承接预定动作。静帧通过不证明动画、口型或声音通过。

按主因修复：错脸检查参考，手物关系改动作或局部编辑，文字错修文字层，风格漂移检查参考职责。保留有效部分并记录变量。同类问题重复时按 [验收](review.md) 重审设计，不无限盲抽。

交付实际图片预览、文件、镜头/口播对应、最终提示词、参考用途与检查状态。项目用图按 imagegen 保存要求落入项目目录并回填台账，默认版本化，不覆盖已接受图。讨论预览可留工具默认位置，但须可查看。用户确认、技术检查通过、待修、待选择分别记录。

故事板联系表只是总览，用于后续视频的关键帧需独立清晰单图；九宫格不等于九张可直接用的首帧。未满足尺寸或保存要求时如实报告，不声称已打包完成。
