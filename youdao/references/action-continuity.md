# 动作因果与连续性

仅用于动作是主要信息的片段：追逐、对抗、跌落、舞蹈、机械操作和复杂接触。普通口播无需套用动作戏节奏。

先确认参与者、目标、站位、移动方向、道具归属、接触点和起始重心。把关键动作写成：**动机/触发 → 发力与轨迹 → 接触或落空 → 可见反馈 → 新处境**。新处境改变位置、优势、物件状态或下一步选择；不能让两人反复交换姿势却没有进展。

每个节拍只保留观众需要辨认的动作，明确谁先动、谁响应。接触须在空间上可达；力的方向、身体反馈、物件质量与材质相容。风格化夸张按作品世界规则设计，不冒充物理准确。声音来自实际可见的移动、碰撞或环境，不强制每次动作扬尘、火花、慢镜或重低音。

镜头服务关键接触与反应。观众尚未辨认攻守或操作关系时，减少遮挡和无依据切镜；必要时用全景建立位置，再用近景强调。强度、停顿、战术改变和结尾由内容决定，不固定秒数、比例或必留续集钩子。

连续生成以前一段实际接受的末态为依据：姿势、朝向、重心、持物手、伤损、场景位置和动势。静帧只能验证瞬时状态；视频要正常速度查看接触、受力和反应是否连续。失败先定位为设计不可行、参考不足、生成偏差或剪辑遮蔽，再修最小受影响段。
