# 视听规划与画布交付

## 完整短片的前置视听规划

当整片涉及多段情绪、音乐进出与剪辑协调，或用户明确要求规划图时，产出可打开的图。已有清楚的时间线可复用；单镜、简单口播配图和局部小修用必要的镜头/声音说明即可。

事件、关键选择或结尾改变时更新曲线与音乐节点；只改措辞且节拍未变时复用。节点数量随实际事件，不固定8—14个。紧张、温暖、自豪等标注类别，数值若使用仅代表主观规划强度；不强制用“窒息”描述所有高潮。

与剧本同步产出可打开的图及逐段说明；用户已确认剧本时据其反推，不暗改剧情。横轴使用成片秒数；情绪曲线注明是主观创作目标，明确跟踪观众投入或角色情绪，不把紧张、自豪和响度当同一个值。展示事件或信息推进、情绪走向、镜头疏密、音乐节点和关键声音；仅在采用风格切换时标其位置。没有固定的最佳曲线，勿为抬高曲线添加无关冲突。

音乐建议包含：功能、配器/质地、有无人声、速度区间（适用时）、进出点、对白让位点、结尾收束。速度不等于切镜频率；不强迫所有切镜踩拍。选曲名称、价格与授权须查证；风格建议不等于已有可用音乐文件。为配乐连续性区分整片后期配乐与模型同期音效，不把给剪辑者的工作写进视频生成提示词。

## 画布交付的三个层次

1. 本地任务包：图、词、剧本段、音频说明、参数与任务ID一一对应。
2. 外部画布：创建文本/素材/生成节点，绑定参考，分组排布，返回画布链接。
3. 执行生成：调用计费模型、等待结果、回收视频和验收。

明确本次到哪一层；导入不代表已生成，节点连线不代表参考真的绑定。只有已实际测试的能力标为可用。

先核验平台官方入口、当前登录账号、目标画布和接口。首选官方API/CLI或平台导入格式，UI自动化仅为经验证的备选，不承诺任意网站均可一键。外部平台的Agent不能自行改写已确认剧本和身份资产。

画布映射最少记录：任务ID、剧本版本、资产文件及用途、文本内容、请求秒数、节点ID、分组、依赖、结果链接。写入前读取目标画布；精确匹配已有资产，避免重复节点和重复收费。导入后回读文本、素材数量、参考关系、参数与链接。先用一个任务验证再批量导入，失败可接着未完成步骤继续，不重跑所有任务。

用户授权导入素材不自动扩展为不限额生成。身份登录由用户完成；费用沿用明确预算，未知则在运行付费任务前确认。支持哪些模型及模式以当前官方说明和实际界面为准。

平台入口、登录、接口、测试日期和限制写入当前项目的环境记录；技能不保存某台机器曾安装或未安装的状态，不能用历史教程推定当前 API 可用。


## 剪辑落点与声音分工

先找原声中的重读、停顿与语义转折，再安排音乐段落和重要动作。音乐速度、口播词时与切镜时间分别考虑；必要时用音量自动化、对白让位和短暂收声组织层次，不只整段循环背景音乐。

区分铺底音乐、运动/接触音与重点冲击：运动音按可见动作的起止布置，冲击留给少数真正需要强调的落点。避免全程同一种whoosh、低频重击与视觉无关，或音效掩盖关键辅音。响度与峰值检查通过后仍要正常速度试听；无法试听时准确标明未核验听感。
