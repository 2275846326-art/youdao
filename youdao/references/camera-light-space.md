# 空间、镜头与灯光

用于有空间调度、运镜、真实场景或图生视频的镜头。纯字幕修正、普通图表不必填写摄影表。先写镜头让观众看懂什么，再选择手段。

## 首帧的六层检查

实际查看参考图，按当前动作检查：主体身份及状态；前中后景与尺度；遮挡和出入口；地面/承重/接触；视线、轴线与移动方向；光源及投影。每项区分“图中实见／其他参考支持／未知或设计提案”。单张图看不见的背面、道路转角和建筑内部不能当已知事实。

将镜头风险分为三档，用于选择验证范围，不作为固定审批流程：
- A：保持已见空间，固定或小幅调整，主要变化来自主体。
- B：移动显露少量未知区域，或涉及遮挡、转身、接触；补关键参考或先试一个代表段。
- C：大幅环绕、穿越、多主体交错或关键结构背面未知；先补空间证据，或采用能表达同一内容的分镜。用户明确选择探索性生成时标明推演，不能伪装成真实建筑/产品证明。

首帧通过后才能作为该镜头输入；未知背景不自动阻止不依赖它的镜头。

## 镜头与灯光卡

沿用已有镜头表，只补会影响执行的字段：

| 项目 | 需要做出的决定 |
|---|---|
| 观看任务 | 展示哪个动作、信息或关系；何时被看清 |
| 起点 | 景别、机位高度/角度、主体位置与视线 |
| 路径 | 固定/移动；经过哪里；哪些区域会新进入画面 |
| 速度与节拍 | 何时启动、变化、停稳；是否影响读字/看动作 |
| 跟随关系 | 摄影机跟谁；主体如何运动；焦点如何转移 |
| 终点 | 最终构图、主体状态、下一镜的接点 |
| 主光依据 | 窗、太阳、灯具或风格化设计；位置、方向、软硬 |
| 光比与色彩 | 主体和背景明暗、色温关系、肤色/产品固有色 |
| 连续性 | 时间、天气、光向、影子与前后镜是否一致 |

写清摄影机与主体各自的运动，避免把变焦、推轨、人物靠近混为一件事。路径不得穿过实体障碍。主体/文字尚未读清时，先调整运动和展示时间。固定镜头与自然光都是有效选择；不强制多种运镜、轮廓光或“电影质感”。

## 翻译到制作

静图只写此刻状态、构图和光线，运动留给视频；母图以清楚识别为目标，情境光留给镜头。实拍检查设备与可达位置；生成镜头核对参考覆盖；程序镜头核对坐标、遮挡和中间态。参数依实际平台，不把相机品牌、镜头名称或某套调色预设当质量保证。

验收先看空间、动作和注意力，再看装饰。不将运动词数量当可行性评分；“无环绕”不是一次环绕。自动脚本不判断空间真实或审美。
