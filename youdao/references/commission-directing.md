# 跨类型导演方法

这是基于现有柚导方法与通用导演知识整理的工作规则，尚非各类型实战验证库。遇到产品参数、建筑现状、活动事实、平台规格或授权等具体主张，另查原始资料，不用通用经验代替核实。

## 共同起点与路由

开始制作先判类型，再选方法，不先挑转场模板。判定依据是观众要理解/感受/采取什么行动、内容怎样推进、现有素材能证明什么；风格不是类型。知识类口播/财经科普走 [知识类口播包装](knowledge-presenter.md)，其他原片口播按 [原声与解释性动效](narration-motion.md)。混合制作在各段局部切换方式，保持主类型的推进逻辑。

先明确：作品给谁看、在哪里看、希望留下什么认知/感受/行动、最重要的一条信息、凭什么让人相信、制作条件及交付规格。能从资料得出的自行整理，只有影响创意方向和执行的缺口才问。

| 类型 | 主要推进逻辑 | 优先验收 |
|---|---|---|
| 剧情短片/短剧 | 人物目标→阻碍→选择→结果 | 因果与情绪是否成立 |
| TVC/产品广告 | 使用需求→产品作用→可见证据→品牌记忆 | 卖点准确、证据明确、品牌可辨 |
| 品牌形象片 | 价值主张→真实行动→受益证据→情感归属 | 价值是否由事实支撑 |
| 活动影像 | 真实进程→关键事件→参与反应→活动价值 | 关键瞬间覆盖、时间关系、真实反应 |
| 建筑影像 | 场地→接近→门槛→空间展开→使用体验 | 地理空间、尺度、材质与光线连续 |
| 楼盘影片 | 目标人群需求→空间与配套证据→生活体验 | 现状/规划区别、空间真实、价值可理解 |
| 真人口播/知识说明 | 原话主张与条件→例证或解释→结论与回调 | 语义准确、原声时间、证据身份、观看负担 |
| MG/动态图文 | 观看问题→关系或形态变化→可辨认结果 | 动作表达、文字阅读、焦点与交接 |

同一项目可组合，先选主要逻辑，再局部借用其他形式。品牌产品可无对白；建筑可慢节奏；活动可纪实。不要机械套用倒计时、身份反转、九宫格或Q版。

## TVC与产品

先做一条“主张—证据—镜头—记忆点”链。每个性能、材质、工序和对比来自什么资料须可追溯。无证明的部分只做设计提案，不能用演示或特效伪装测试结果。

产品锁定型号、尺寸比例、形态、颜色、接口、标识和使用状态。英雄镜头负责识别与欲望，功能镜头负责说明作用，生活镜头负责证明意义；三类按目的取舍，不平均分配。复杂结构用真实资料或可信三维资产，AI生成不得擅自增加零件。品牌文字可留给可控后期制作。

选择一个清晰创意机制，如使用前后体验、尺度对比或动作匹配；连续奇观必须仍能让人说出产品是谁、价值是什么。交付包含核心诉求、创意概念、产品证据表、节奏与声音、关键镜头、末版品牌落点。购买行动只在项目需要时加入，不为形象片强加促销。

## 活动导演

先区分：现场屏幕/直播导演、活动宣传片、活动回顾片。三者不能混为一份拍摄清单。读流程表并定位不可重来事件、关键嘉宾、观众反应、舞台屏幕内容和收音需求。

实拍覆盖表按“事件时间/位置—主机位—备用覆盖—反应镜头—声源—负责人或待分配”规划。单机同时拍台上动作与台下反应不可保证，明确覆盖优先级或所需机位。时间重叠先解决，不靠剪辑补造现场事实。

预热片可以设计情境；回顾片按真实事件与合法可用素材剪辑，不把AI生成嘉宾、观众规模、掌声或发言冒充现场。需要补拍或示意时明确素材性质。镜头以事件、参与及反应推进，避免空镜和Logo连放却看不出活动发生了什么。直播另交机位/切换提示、屏幕素材、流程与异常备选，不宣称助手已具备现场导播控制。

## 建筑与楼盘导演

建筑片表达空间与设计；楼盘片还需回应目标使用者的需求。读平面图、现场照片、朝向和建筑现状，标明实测、资料标注及设计推演。无依据不编交通时间、面积、交付标准或规划兑现；涉及销售事实时另核验。

先定一条空间体验路径：外部定位、接近入口、跨越门槛、主空间、关联空间、重要细节、回望。每次切换让观众理解位置或增加对空间的感受，不能把无关美景拼成不存在的户型。

固定门窗、层高比例、柱网、材料、室内外关系和光源方向；先用俯视布局与必要方向参考补齐镜头，不凭一张正面照声称恢复完整360度空间。新角度属推演时注明，重点核对反打和开门后的空间。镜头高度、视角和运动速度服务尺度感，不用超广角或虚假窗外景夸大空间。

时段与光线变化要有意图。航拍用于位置关系与体量，地面镜头用于人的体验，细节用于材料与工艺；是否用航拍取决于实际可用素材和拍摄条件。AI想象未来生活时，与真实现状、规划图像清楚区分。交付空间路径、场景锚点、机位/调度图、光线时段、镜头与声音计划及事实核验项。

## 实拍、AI、混合制作的不同交付

口播内容与时间按 [口播模块](narration-motion.md)，动态图文和人物合成按 [动态图文模块](motion-layout.md)。普通口播、克制字幕或二维图解不因加入这些路径就强制抠像、三维化或增加片头。

- 实拍：导演阐述、分镜、场景与道具需求、人物表演、机位覆盖、拍摄顺序、收音、时间条件和后期方案；不把生成提示词作为必须产物。
- AI：按 production.md 交付图词同卡、参考职责、秒数、模型模式、验收及接续状态。
- 混合：逐镜标实拍/AI/合成，声明交接需要的构图、光向、运动方向、尺度、干净底板或音轨；无法取得的素材明确为缺口。
- 程序动效：在可用引擎中实现文字、图形、数据与合成时间线，交付媒体和代码工程；执行与验收见 [制作执行](execution-adapters.md)。可与原片或生成素材组合，不自动改成生成模型任务。

所有路径都先交创意与可执行方案，再用实际素材复核。专业名词只有能改变制作决策时才使用，不能把器材型号堆砌当导演能力。
